## a / an — count and no-count

There are two kinds of things — those that we can count and those that we can not. If we can put a number before a word, we normally put "a/an" in place of 1.

- This is a chicken. — These are two chickens.
- This is a pie. — These are three pies.
- This is a chocolate cake. — These are four chocolate cakes.
- This is an apple. — These are five apples.
- This is an egg. — These are six eggs.
- This is an onion. — These are seven onions.
- This is bread. / This is water. / This is sugar. / This is butter. / This is rice. / This is ice cream.

## some

To give the idea of only part of a thing we put some before the thing.

- This is a fish. — This is some fish.
- This is a banana. — This is some banana.
- This is a pie. — This is some pie.
- This is an egg. — This is some egg.
- This is an apple. — This is some apple.
- This is an orange. — This is some orange.
- This is bread. — This is some bread.
- This is butter. — This is some butter.
- This is salt. — This is some salt.
- This is ice. — This is some ice.
- This is cheese. — This is some cheese.
- This is money. — This is some money.

## on / off

on normally has relation to a surface.

- Some butter is on my bread.
- Some nuts are on your ice cream.
- Some pepper is on their food.
- Three buttons are off his sweater.
- The skin is off the onion.
- Is the egg on or off his face?
- Her coat is off.
- His shoes are off.

## Present — to be

- I am / we are
- you are / you are
- he is / they are
- she is
- it is

- I am happy. — I am not happy.
- He is sad. — He is not sad.
- She is very sweet. — She is not very sweet.
- They are too good. — They are not too good.

- Am I? / Are we? / Are you? / Is he? / Is she? / Is it? / Are they?
- Are you too cold? — Are you not too cold?
- Is he too hot? — Is he not too hot?
- Is she very beautiful? — Is she not very beautiful?
- Is it very expensive? — Is it not very expensive?

## How much (money)...?

- How much money is this? — That is $1.00 (one dollar).
- How much money is this? — That is $5.00 (five dollars).
- How much money is this? — That is $10.00 (ten dollars).
- How much money is this? — That is $20.00 (twenty dollars).
- How much is pepper cheese? — Pepper cheese is $1.00.
- How much is fresh butter? — Fresh butter is $2.00.
- How much is sweet and sour pork? — Sweet and sour pork is $3.00.
- How much is beef and fried rice? — Beef and fried rice is $4.00.
- How much are these? — Those are $.20 (twenty cents).
- How much are these butter chocolates? — Those butter chocolates are $.25.
- How much are these nut candies? — Those nut candies are $.35.
- How much are these blueberries? — Those blueberries are $.45.
- How much are these green beans? — Those green beans are $.55.
